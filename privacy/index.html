01

Who this applies to

GTA6 Shorts Uploader has a single user: the developer who operates it. It has no public sign-up, no visitor accounts, and no audience whose data it could collect. This policy exists to document how the operator's own data — most relevantly, their TikTok authorization — is handled.

02

Data handled

DataPurpose
TikTok OAuth access & refresh tokensAuthenticate upload requests to the operator's own TikTok account
Rendered video filesUploaded as private drafts to the operator's TikTok inbox
Script text and captionsUsed to generate video content and suggested captions

No analytics, tracking pixels, cookies, or third-party advertising SDKs are used anywhere in the tool.

03

Data shared with TikTok

The only external service this tool communicates with is TikTok's own Content Posting API. Each upload sends the finished video file and, once TikTok grants full posting access, a caption. TikTok's handling of that data is governed by TikTok's own Privacy Policy.

04

Storage and retention

All data — tokens, rendered videos, scripts — stays on the operator's own machine. Tokens are kept in a local environment file, not in any database or cloud service, and are retained only for as long as the tool is in use. Deleting that file revokes local access immediately.

05

Third-party sharing

Nothing is sold, rented, or shared with any party other than TikTok, and only for the purpose described above.

06

Access and deletion

Since the operator is the only person whose data this tool holds, they control it directly: deleting the local environment file removes stored tokens, and revoking access from TikTok's own account settings ends the authorization at TikTok's end.

07

Changes to this policy

This page may be updated as the tool changes. The effective date at the top reflects the latest revision.
